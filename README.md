# Plataforma Web para Estudio de Fotografía y Producción Audiovisual

## Descripción

Aplicación web full stack desarrollada para la gestión de usuarios y reservaciones de un estudio de fotografía y producción audiovisual.

La plataforma permite a los clientes registrarse, iniciar sesión y agendar sesiones fotográficas. Además, cuenta con un sistema de usuarios con roles que permite controlar el acceso a diferentes funcionalidades.

## Tecnologías utilizadas

### Frontend
- React
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Base de datos
- MongoDB
- Mongoose

### Herramientas
- Postman
- Git/GitHub

## Funcionalidades

- Registro e inicio de sesión de usuarios.
- Autenticación mediante JWT.
- Cifrado de contraseñas utilizando bcrypt.
- Sistema de roles:
  - Administrador
  - Socios
  - Asistentes
  - Clientes
- Creación, consulta, actualización y eliminación de reservaciones.
- Rutas protegidas mediante middleware de autenticación y autorización.
- API REST para comunicación entre frontend y backend.
